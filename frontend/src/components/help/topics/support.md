- **These articles, online.** [flows.lab34.es/docs](https://flows.lab34.es/docs/)
  carries the same articles as this Help section, generated from the same
  files.
- **The examples are documentation too.** The seeded `01 · Welcome`,
  `02 · HTTP basics`, `03 · Posts and memory` and `04 · Browser, scraping and
  memory` flows, and the `calculator`, `httpbin`, `jsonplaceholder` and
  `browser` applications, are meant to be read as much as run. They are only
  copied when missing, so edit them freely, or delete them and get them back
  on the next start.
- **The source.** [github.com/lab34-es/flows](https://github.com/lab34-es/flows).
  The README covers how the package is built, tested and released.
- **Bugs and ideas.** Check [Troubleshooting](/help/troubleshooting) first, then open an issue at
  [github.com/lab34-es/flows/issues](https://github.com/lab34-es/flows/issues).
  The output of `--debug`, the flow, and the version from
  `lab34-flows --version` make it answerable.
